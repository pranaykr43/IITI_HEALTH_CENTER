# Oracle Cloud Always Free setup

1. Create an Oracle Cloud account and carefully choose its home region. Sign-up may ask for a payment card and phone number. Do not select **Upgrade** or create resources without the **Always Free-eligible** label. Oracle's time-limited trial credits (up to $300 for up to 30 days) are separate from Always Free and are not required for this setup. [Oracle Free Tier](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier.htm)
2. In the home region, inspect **Limits, Quotas and Usage**. Confirm A1 capacity. The Always Free A1 pool is up to 1,500 OCPU-hours and 9,000 GB-hours monthly (equivalent to 2 OCPUs and 12 GB); storage limits include 200 GB combined boot/block volume. If A1 says out of host capacity, wait or try another availability domain in the home region. Do not upgrade to paid to bypass capacity.
3. Create one Ubuntu ARM64 VM with no more than 2 OCPUs and 12 GB RAM. Confirm the boot volume and any attached volume are Always Free. Open TCP 22 only to your administration IP and TCP 80/443 to the public internet. Keep SQLite and app ports private. Restrict SSH with key-based login; disable password SSH after confirming key access.
4. Reserve a public IPv4 address and point a DNS A record to it. If you do not own a domain, DuckDNS currently offers free dynamic-DNS subdomains; register a subdomain and update it to the reserved VM address over its HTTPS updater. Treat the DuckDNS update token as a secret, keep its updater configuration readable only to the service operator, and recheck its terms because the service can change. [DuckDNS FAQ](https://www.duckdns.org/faqs.jsp), [DuckDNS overview](https://www.duckdns.org/why.jsp). Caddy will obtain HTTPS certificates automatically after public DNS resolves and ports 80/443 reach the VM. [Caddy automatic HTTPS](https://caddyserver.com/docs/automatic-https). Avoid exposing an IP-only hostname that cannot satisfy the certificate issuer.
5. Install Docker Engine and the Compose plugin using the official Ubuntu instructions. Clone the intended feature branch to the VM, create an owner-readable `.env` from `production.env.example`, set `PUBLIC_HOST` and `PUBLIC_BASE_URL`, and generate/set secrets on the VM without echoing them into shell history. Keep `.env` mode 600 and out of Git.
6. Run `docker compose build`, then `docker compose up -d web caddy`. Check `docker compose ps` and `https://your-host/readyz`. Run `docker compose run --rm web npm run admin:create` in an interactive terminal to create the one-time admin. Provision the first doctor inside the authenticated admin workflow.
7. Start and verify the worker with `docker compose up -d worker`; Compose also starts it after `/readyz` is healthy. Run a synthetic appointment through the browser and verify the event is logged locally. Never use real clinic or patient data.
8. Create an Object Storage bucket in the home region with a retention lifecycle. Always Free object storage provides 20 GB combined and 50,000 API calls per month on an Always Free-only account, enough for a small synthetic demo's daily SQLite backups if they stay within quota. Configure the OCI CLI on the VM with a least-privileged identity and set `OCI_BACKUP_BUCKET` in the backup cron environment. Backups stored only on the VM do not protect against VM loss or reclamation.

Oracle may reclaim idle A1 instances when all specified low-utilization conditions apply over seven days (CPU, network, and memory utilization below 20% at the documented percentile). Do not generate artificial load to avoid reclamation. Keep an off-VM backup, monitor account notices, and document that the demo may be unavailable if free capacity is reclaimed. [Oracle Free Tier](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier.htm)

There is no guarantee that A1 capacity exists in every home region. If the account shows no Always Free capacity, do not use a paid shape under the zero-cost requirement. Pause and revisit later or choose the Cloudflare option described in [free-hosting-comparison.md](free-hosting-comparison.md), which requires a significant data and runtime migration.
